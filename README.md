# 🍗 The Great Biryani Mystery

### 🔎 A Funny Python Detective Game

Someone has stolen the biryani! 😱

Five suspects, suspicious clues, and only **3 chances** to catch the thief. Can you solve the case before the biryani disappears forever?

---

## 🎮 About the Game

**The Great Biryani Mystery** is a fun, terminal-based detective game built using Python. You play as a detective investigating a hilarious biryani theft.

Each round randomly selects a culprit. Your mission is to identify the thief using the clues provided. Choose wisely, because you only have three chances!

## ✨ Features

- 🎲 Random culprit selection in every game
- 🕵️ Five funny suspects with unique clues
- ❤️ Three chances to solve the mystery
- 😂 Funny messages and unexpected outcomes
- 🖥️ Simple command-line interface
- 🐍 Built using basic Python concepts
- 📦 No external libraries required

## 🛠️ Technologies Used

- **Python 3**
- `random` — selects the culprit randomly
- `time` — available for timing or suspense effects
- `input()` and conditional statements
- Loops, dictionaries, and lists
